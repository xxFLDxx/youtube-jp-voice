# 日本語音声でYouTube（第1段階・お試し版）

英語のYouTube動画を、日本語の読み上げ音声と日本語字幕つきで見るための自分専用Webアプリです。
第1段階では有料APIにはつながず、**見本データだけ**で動きます。

- 動画は YouTube 公式の埋め込みプレーヤーで、音を消して再生します
- 日本語の声は、ブラウザに入っている読み上げ機能で出します
- 動画や音声のダウンロード、字幕の自動取得は行いません

## 動かし方（GitHub Pagesで公開する・画面操作だけ）

最初に1回だけ設定します。パソコンでもスマホのブラウザでもできます。

1. GitHub でこのリポジトリのページを開く
2. 上のメニューの **Settings**（歯車のマーク）を押す
3. 左のメニューの **Pages** を押す
4. 「Build and deployment」の **Source** が **Deploy from a branch** になっていることを確認する
5. その下の **Branch** で、ブランチ名（アプリのファイルが入っているブランチ）を選び、右隣は **/ (root)** のままにして **Save** を押す
6. 1〜2分待ってからページを再読み込みすると、上部に公開先のURLが表示される
   （`https://<ユーザー名>.github.io/youtube-jp-voice/` の形）
7. そのURLを開けばアプリが使えます。スマホのホーム画面やブックマークに登録しておくと便利です

ファイルを更新すると、1〜2分で自動的に公開先にも反映されます。

> 注意: `index.html` をパソコンに保存して直接開く方法では、YouTubeのプレーヤーが動きません。必ず上の公開URLから開いてください。

## 使い方

1. **URL入力** … 「見本の動画」の名前を押すとURLが入るので、「変換する」を押す
2. **変換一覧** … 動画を押すと再生画面に進む
3. **再生** … 「▶ 再生」ボタンを押す。一時停止・移動（シーク）・速度変更をしても声が追いかけます（文は途中で切らず、読み終えてから次へ進みます）

うまくいかないとき:

- **声が出ない** … 動画の中の再生ボタンではなく、動画の下の「▶ 再生」ボタンを押してください（スマホは最初の1回、画面のボタンを押す必要があります）。端末の消音モードや音量も確認してください
- **声が不自然／日本語にならない** … 端末に日本語の読み上げ音声が入っていない可能性があります。端末の設定（読み上げ／テキスト読み上げ）で日本語音声を追加してください
- **「埋め込み再生が許可されていません」** … 動画の投稿者が埋め込みを禁止しています。別の動画を使ってください

## 見本データの形

`data/samples/<動画ID>.json` に、動画1本分を置きます。

```json
{
  "videoId": "動画ID",
  "title": "一覧に出すタイトル",
  "segments": [
    { "start": 1.0, "end": 5.0, "text": "日本語の文" }
  ]
}
```

- `start` / `end` は動画の先頭からの秒数
- 見本を増やすときは `data/samples/index.json` にも1行足します
- いま入っている見本の日本語文は動作確認用で、動画の内容の翻訳ではありません

## 作り（次の段階で差し替える場所）

| ファイル | 役割 |
| --- | --- |
| `js/config.js` | **差し替え口**。翻訳の部品と音声の部品をここで選ぶ |
| `js/providers/transcript-sample.js` | 翻訳の部品（今は見本JSONを読むだけ）→ 翻訳AIに差し替え |
| `js/providers/speech-browser.js` | 音声の部品（今はブラウザ読み上げ）→ 音声合成に差し替え |
| `js/sync.js` | 再生位置と声を合わせる仕組み（差し替え不要） |
| `js/views/` | 3つの画面（URL入力・変換一覧・再生） |
| `js/youtube.js` | YouTube公式プレーヤーの読み込み、URLの読み取り |
| `js/store.js` | 変換一覧の保存（このブラウザの中だけ） |

同期の考え方: 0.1秒ごとに再生位置を確認し、新しい文に入ったら読み上げます。
読み始めた文は途中で切らず、読み終えてから次の文へ進みます。声が遅れた分は、
文と文のすき間と少しの早口で取り戻します（大きく遅れたときだけ、間の文を飛ばして追いつきます）。
一時停止・シークのときは声を止め、今の位置の文から読み直します。
読み込み待ち（バッファリング）では声を止めません。
再生速度を変えたときは、読んでいる文を読み終えてから、次の文で新しい速度になります。
ブラウザの読み上げは文の途中から始められないため、同期は「文」単位です
（音声ファイルを再生する部品に差し替えれば、途中からの再生もできる作りにしてあります）。
