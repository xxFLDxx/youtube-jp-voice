# 日本語音声でYouTube

英語のYouTube動画を、日本語の音声と日本語字幕つきで見るための自分専用Webアプリです。

- 動画は YouTube 公式の埋め込みプレーヤーで、音を消して再生します
- YouTube の「文字起こしを表示」からコピーした英語の文字起こしを貼り付けると、
  Claude（Sonnet 5.5）が自然な話し言葉の日本語に翻訳します
- 声は Google Cloud Text-to-Speech（Chirp 3 HD）で、変換のときに全文ぶん作ってブラウザ内に保存します
- 鍵を設定していないときは、見本データとブラウザの読み上げ機能で動きます
- 動画や音声のダウンロード、字幕の自動取得は行いません

## 動かし方（GitHub Pagesで公開する・画面操作だけ）

最初に1回だけ設定します。パソコンでもスマホのブラウザでもできます。

1. GitHub でこのリポジトリのページを開く
2. 上のメニューの **Settings**（歯車のマーク）を押す
3. 左のメニューの **Pages** を押す
4. 「Build and deployment」の **Source** が **Deploy from a branch** になっていることを確認する
5. その下の **Branch** で、ブランチ名（アプリのファイルが入っているブランチ）を選び、右隣は **/ (root)** のままにして **Save** を押す
6. 1〜2分待ってからページを再読み込みすると、上部に公開先のURLが表示される
   （`https://<ユーザー名>.github.io/youtube-jp-voice/` の形）
7. そのURLを開けばアプリが使えます。スマホのホーム画面やブックマークに登録しておくと便利です

ファイルを更新すると、1〜2分で自動的に公開先にも反映されます。

> 注意: `index.html` をパソコンに保存して直接開く方法では、YouTubeのプレーヤーが動きません。必ず上の公開URLから開いてください。

## 使い方

### まず鍵なしで試す

1. **URL入力** … 「見本の動画」の名前を押すとURLが入るので、文字起こしの欄は空のまま「変換する」を押す
2. **変換一覧** … 動画を押すと再生画面に進む
3. **再生** … 「▶ 再生」ボタンを押す

### 本物の翻訳と自然な声で見る

先に下の「鍵の準備」を済ませ、アプリの **設定** 画面で鍵を保存しておきます。

1. YouTubeで見たい動画を開き、説明欄の下のほうにある **「文字起こしを表示」** を押す
2. 出てきた文字起こしを、最初の行から最後の行までドラッグして選び、コピーする
3. アプリの **URL入力** 画面で、動画のURLを貼り、「英語の文字起こし」の欄に貼り付ける
4. 欄の下に **文字数と料金の目安** が出るので確認して「変換する」を押す（確認の窓が出ます）
5. 進み具合（翻訳 → 音声）が表示され、終わると **変換一覧** に移る
6. 動画を押して **再生**。一時停止・移動（シーク）・速度変更をしても声が追いかけます

手順1〜3の「選んでコピー」は、下のブックマークレットを使うとボタン1回で済みます。

### 文字起こしをワンクリックでコピーする（ブックマークレット・パソコン向け）

ブックマークレットは、ブックマークとして登録しておく小さなプログラムです。
YouTubeの動画ページで押すと、文字起こしパネル（閉じていれば自動で開きます）の内容を、時刻つきで全部クリップボードにコピーします。

**登録のしかた（最初に1回だけ）**

1. ブラウザのブックマークバーを表示する（Chrome・Edge は `Ctrl+Shift+B`、Mac は `⌘+Shift+B`）
2. このアプリの **URL入力** 画面を開き、文字起こしの欄の下にある **「ワンクリックでコピーする（ブックマークレット・パソコン向け）」** を押して開く
3. 青い **「文字起こしコピー」** ボタンを、マウスでつかんでブックマークバーまで **ドラッグ** して離す

ドラッグがうまくいかないときは、次の方法でも登録できます。

1. 同じ場所の **「コードをコピー」** を押す
2. ブックマークバーの上で右クリック → **「ページを追加」**（または「ブックマークを追加」）を選ぶ
3. 名前に `文字起こしコピー`、URL の欄にコピーしたコードを貼り付けて保存する

**使い方**

1. YouTubeで見たい動画のページを開く
2. ブックマークバーの **「文字起こしコピー」** を押す
3. 画面右上に「文字起こし ○ 行をコピーしました」と出たら、アプリの **URL入力** 画面の「英語の文字起こし」の欄に貼り付ける
   （動画のURLと名前も自動で入ります）
4. あとは料金の目安を確認して「変換する」

うまくいかないとき:

- **「下のボタンを押すとコピーします」と出る** … そのボタンを押してください（ブラウザの都合で、自動でコピーできない場合があります）
- **「英語ではないようです」と出る** … 文字起こしパネルの下にある言語の選択を英語に切り替えてから、もう一度押してください
- **「文字起こしを見つけられませんでした」と出る** … 説明欄の「文字起こしを表示」を手で押してから、もう一度押してください。それでもだめなら、その動画には文字起こしがありません
- スマホのブラウザでは、ブックマークレットは使いにくいため、パソコンでの利用を想定しています

このブックマークレットが読むのは、YouTubeのページに表示されている文字起こしパネルの文字だけで（手で選んでコピーするのと同じ内容です）、どこにも送信しません。
アプリ本体は、今までどおり動画・音声・字幕を自分から取りに行くことはしません。中身は `bookmarklet/transcript-copy.js` で確認できます。

知っておくこと:

- 変換結果（翻訳と音声）は、**変換したブラウザの中だけ**に保存されます。パソコンで変換したものはスマホには出ません
- 途中で失敗・中断しても、できた分は残ります。変換一覧の「続きから再開」か、同じ文字起こしのままもう一度「変換する」で続きから進みます（翻訳済みの分は課金されません）
- 文字起こしが用意されていない動画は変換できません
- 音声の作成は、Googleの上限（1分に60回）に当たらないよう **1分に50文まで** のペースで進みます（300文の動画で約6分）。それでも上限に当たったときは、残り秒数を表示しながら1分待って、自動で続きから再開します
- Googleの **1日あたりの上限** に当たったときは、止めてお知らせします。上限が元に戻ってから「続きから再開」を押してください
- 最初は数分の短い動画で試すのがおすすめです

### うまくいかないとき

- **声が出ない** … 動画の中の再生ボタンではなく、動画の下の「▶ 再生」ボタンを押してください（スマホは最初の1回、画面のボタンを押す必要があります）。端末の消音モードや音量も確認してください
- **「埋め込み再生が許可されていません」** … 動画の投稿者が埋め込みを禁止しています。別の動画を使ってください
- **「Googleに拒否されました」** … 下の「Googleの鍵の取り方」の、APIの有効化・支払い設定・鍵の制限（サイトのアドレス）を見直してください
- **「Claudeがリクエストを受け付けませんでした」** … 残高（クレジット）不足のことが多いです。Console の Billing を確認してください
- エラーの文には「詳細: …」が付きます。直らないときは、その文をそのまま伝えてもらえると原因を調べやすくなります

## 鍵の準備（最初に1回だけ）

登録・支払い・上限の設定は、それぞれのサービスの画面でご自身で行います。
画面の表示名は変わることがあるので、見当たらないときは近い名前の項目を探してください。

**鍵の扱いの注意**

- 鍵はパスワードと同じです。チャット・メール・GitHub には貼らないでください。貼る先は、このアプリの **設定** 画面だけです
- 鍵は設定画面を開いたブラウザの中だけに保存されます。共用のパソコンでは保存しないでください
- もし鍵を人に見られたかもしれないときは、各サービスの画面でその鍵を削除（無効化）して作り直してください

### Claudeの鍵の取り方（翻訳用）

1. ブラウザで **https://platform.claude.com** を開き、アカウントを作ってログインする
   （Claude のチャット用アカウントとは別に、API 用の「Console」のアカウントと支払いが必要です）
2. 左のメニューの **Settings（設定）→ Billing（請求）** を開き、支払い方法を登録して **クレジットを購入** する
   - 前払い式です。最初は最低額（5ドル程度）で十分です
   - **Auto reload（自動チャージ）はオフ** のままにしておくと、買った分を使い切った時点で止まるので、使いすぎの心配がありません
3. さらに上限を決めたい場合は **Settings → Limits（上限）** で、月ごとの利用上限額（Spend limit）を設定する
4. **Settings → API keys** を開き、**Create Key** を押す。名前は何でもかまいません（例: `youtube-jp-voice`）
5. 表示された `sk-ant-…` で始まる鍵をコピーする（**この画面を閉じると二度と表示されません**）
6. このアプリの **設定** 画面を開き、「Claudeの鍵」に貼り付けて **保存**。「この鍵は使えます」と出れば完了です

料金の目安: 入力100万トークンあたり2ドル、出力100万トークンあたり10ドル。10分の動画で0.1〜0.2ドル前後、1時間で0.3〜1ドル前後です（変換前の画面に、その動画での目安が出ます）。

### Googleの鍵の取り方（音声用）

1. ブラウザで **https://console.cloud.google.com** を開き、Googleアカウントでログインする
2. 初回は利用規約に同意し、画面上部のプロジェクト選択から **新しいプロジェクト** を作る（名前は何でもかまいません）
3. 左上のメニュー（三本線）→ **お支払い** を開き、**請求先アカウント** を作ってクレジットカードを登録し、いまのプロジェクトにリンクする
4. 画面上部の検索欄に **Text-to-Speech** と入れ、**Cloud Text-to-Speech API** を開いて **有効にする** を押す
5. メニュー → **API とサービス → 認証情報** を開き、**認証情報を作成 → API キー** を押す
6. できた鍵の編集画面で、**必ず制限をかける**
   - **アプリケーションの制限**: 「ウェブサイト」を選び、アプリのアドレスを追加する
     （例: `https://<ユーザー名>.github.io/*` 。アプリを開いたときのアドレスの、最初の `/` までに `*` を付けたもの）
   - **API の制限**: 「キーを制限」を選び、**Cloud Text-to-Speech API** だけにチェックを入れる
   - **保存** を押す（反映まで数分かかることがあります）
7. `AIza…` で始まる鍵をコピーし、このアプリの **設定** 画面の「Googleの鍵」に貼り付けて **保存**。「この鍵は使えます」と出れば完了です
8. 設定画面の「声の一覧を読み込む」で声を選び、「この声を試聴」で確認できます

**使いすぎ防止の設定（Google）**

- **予算とアラート**: メニュー → **お支払い → 予算とアラート** で、月の予算（例: 5ドル）を作ると、近づいたときにメールが届きます。
  ただし **これは通知だけで、利用は止まりません**
- **確実に止めたい場合**: メニュー → **API とサービス → Cloud Text-to-Speech API → 割り当てとシステム上限** で、
  1分あたり・1日あたりのリクエスト数の上限を小さい値に下げておくと、それ以上は使えなくなります
- 上の手順6の「鍵の制限」も、鍵が漏れたときの歯止めになります

料金の目安: Chirp 3 HD は毎月100万文字まで無料、超えた分は100万文字あたり30ドルです。1時間の動画の日本語は2万文字前後なので、月に数十本までは無料枠に収まる計算です。

## 見本データの形

鍵なしで試すための見本です。`data/samples/<動画ID>.json` に、動画1本分を置きます。

```json
{
  "videoId": "動画ID",
  "title": "一覧に出すタイトル",
  "segments": [
    { "start": 1.0, "end": 5.0, "text": "日本語の文" }
  ]
}
```

- `start` / `end` は動画の先頭からの秒数
- 見本を増やすときは `data/samples/index.json` にも1行足します
- いま入っている見本の日本語文は動作確認用で、動画の内容の翻訳ではありません

## 作り

| ファイル | 役割 |
| --- | --- |
| `js/config.js` | **差し替え口**。翻訳・音声合成・再生時の声に、どの部品を使うかを決める |
| `js/providers/translate-claude.js` | 翻訳の部品（Claude API、公式SDKを使用） |
| `js/providers/tts-google.js` | 音声合成の部品（Google Cloud Text-to-Speech） |
| `js/providers/speech-audio.js` | 再生時の声: 保存済みの音声を再生する部品 |
| `js/providers/speech-browser.js` | 再生時の声: ブラウザの読み上げ機能（鍵が無いとき・音声が無い文） |
| `js/providers/transcript-sample.js` | 見本データを読む部品 |
| `js/convert.js` | 変換の流れ（翻訳 → 音声の事前作成 → 保存、進み具合、続きから再開） |
| `js/transcript-parse.js` / `js/estimate.js` | 貼り付けた文字起こしの読み取り / 料金の目安 |
| `js/sync.js` | 再生位置と声を合わせる仕組み（部品に依存しない） |
| `js/settings.js` / `js/db.js` / `js/store.js` | 鍵と声の設定 / 翻訳と音声の保存 / 変換一覧（すべてこのブラウザの中だけ） |
| `js/views/` | 画面（URL入力・変換一覧・再生・設定） |
| `js/youtube.js` | YouTube公式プレーヤーの読み込み、URLの読み取り |
| `bookmarklet/transcript-copy.js` | 文字起こしコピー用のブックマークレット（YouTubeのページ上で動く。アプリとは別） |
| `vendor/anthropic-sdk.js` | Anthropic 公式SDKをブラウザ用に1ファイルにまとめたもの |

鍵の安全のために:

- 鍵はコードにもリポジトリにも書きません。保存先はブラウザの中（localStorage）だけです
- `index.html` で、このページが通信できる相手を Anthropic・Google・YouTube に限定しています（Content-Security-Policy）
- 外部の配信サーバーからプログラムを読み込みません（YouTube公式プレーヤーを除く）

同期の考え方: 0.1秒ごとに再生位置を確認し、新しい文に入ったら読み上げます。
読み始めた文は途中で切らず、読み終えてから次の文へ進みます。文は飛ばしません。
声が遅れた分は、文と文のすき間と少しの早口で取り戻し、それでも遅れるときは、
声が追いつくまで動画のほうを自動で一時的に止めて待ちます（追いついたら自動で再開します）。
一時停止・シークのときは声を止め、今の位置の文から読み直します。
読み込み待ち（バッファリング）では声を止めません。
再生速度を変えたときは、読んでいる文を読み終えてから、次の文で新しい速度になります。
保存済みの音声は、一時停止やシークのあと文の途中から再生できます。ブラウザの読み上げは文の途中から始められないため、その場合は文頭から読みます。
